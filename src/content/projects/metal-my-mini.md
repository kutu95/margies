A customer uploads a tabletop miniature. The file is checked, printed in UV resin, electroplated in copper and finished by hand.

[metal.margies.app](https://metal.margies.app). I built the software with my son. He does the printing and plating.

## The problem

A 3D file is not a finished object. It can be too thin to plate, the wrong scale, or a format that fails in a slicer. The system has to catch that before printing.

## What it does

The site accepts STL, OBJ and 3MF, takes the order, and queues the file for review. Some checks are automatic. A person still looks at the file before it is printed. Orders can be revised or refunded.

Then: print, plate, polish, photograph, pack. The software keeps the order state honest.

## Why it is here

Most shops sell something that already exists. This one makes the object after the order. The public site and the workshop are one system.
